# Security and privacy

Wordwarden promises that what you write never leaves your device. Anything that breaks that promise is a
security problem, as is anything that lets a website read or change what Wordwarden does.

## Reporting

Please report it privately, not in a public issue: open the repository's **Security** tab and choose
**Report a vulnerability**. Include the browser or LibreOffice version, the Wordwarden version, and the
steps to show the problem.

You will get an answer within a week. Fixes go out as a new release on Firefox Add-ons and GitHub, and
the release notes say what was fixed once the update is out.

## Supported versions

Only the newest release gets fixes. Firefox updates itself from Firefox Add-ons; the Chromium and
LibreOffice downloads need the newest file from
[Releases](https://github.com/Abhisek571/wordwarden/releases/latest).
