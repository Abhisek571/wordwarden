# Wordwarden Privacy Policy

Wordwarden processes writing locally in the browser. It has no account,
analytics, telemetry, advertising, or application server.

Wordwarden does not collect, transmit, sell, or retain text from editable
fields. It never checks password, payment, or one-time-code fields. Saved
settings contain only feature preferences, disabled site names, dictionary
words, and privacy-preserving ignored-issue hashes.

Grammar checking, spelling dictionaries, and word-frequency ranking data are
packaged with the extension and run locally. Correction candidates are never
sent to a server.

Users can delete the dictionary, ignored issues, and all settings from the
options page. Browser and extension updates may use the browser vendor's normal
update service.

When a user chooses **Report issue**, Wordwarden generates a diagnostic report
locally and shows it before sharing. The report contains extension, browser,
platform, feature, runtime, settings, and capability information, plus the
current hostname when Settings was opened from the popup. It contains counts
rather than dictionary words, disabled-site lists, or ignored-issue values. It
does not include user-entered report text, writing, page contents, passwords,
tokens, cookies, API keys, other secrets, or form data, and it is never sent
automatically. Opening the GitHub issue page does not upload or prefill the log;
the user chooses whether to copy and share it.
