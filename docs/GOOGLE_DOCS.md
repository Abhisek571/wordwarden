# Google Docs and online office editors

Google Docs, Sheets and Slides draw the document on a canvas and keep the real
typing target in a hidden frame. Microsoft 365 on the web (Word, Excel,
PowerPoint) keeps the document in an embedded frame. Wordwarden runs in the
top frame only, so it cannot read or fix the document text on these sites.

Wordwarden stays quiet there: no underlines, no pop-ups, and no changes to the
document. The toolbar popup shows a one-line "Known issue" note on these sites.

Do not advertise Google Docs or Microsoft 365 support.
