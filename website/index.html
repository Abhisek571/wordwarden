    Install it

    Free for good: no account, no premium tier. Every version has US, UK, Canadian or Australian English, your own dictionary, and per-site on and off.

    Chrome, Edge, Brave

    Not in the Chrome Web Store. Download the chrome zip, unzip it, open chrome://extensions, turn on Developer mode and choose Load unpacked. This copy does not update itself.
